
# 🛒 বাজার দর | BazarDor

### প্রয়োজনীয় পণ্যের দাম এক নজরে

BazarDor is a responsive web application that helps users explore daily prices of essential products in Bangladesh. Users can compare prices, track daily price changes, browse products by category, and view market-wise pricing information.

## ✨ Key Features

- 📊 **Daily Price Tracking:** View current prices of essential products.
- 📈 **Price Change Indicators:** Identify products with increasing or decreasing prices.
- 🔎 **Product & Category Browsing:** Explore products and filter them by category.
- 🏷️ **Product Details:** View minimum, maximum, and average prices along with market-wise prices.
- 🔐 **Authentication:** Secure user authentication with Better Auth, including email/password, Google, and GitHub login.
- 👤 **Profile Management:** View and update user profile information.
- 📱 **Responsive Design:** Enjoy a smooth experience on mobile, tablet, and desktop.
- 🔢 **Price Sorting:** Sort products by default order, lowest price, or highest price.
- ⚡ **Loading Skeletons & Notifications:** Improve user experience with loading indicators and toast messages.

## 🛠️ Technologies Used

- **Next.js** — React framework and App Router
- **React** — User interface development
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Styling and responsive design
- **DaisyUI** — UI components
- **Better Auth** — Authentication and session management
- **MongoDB** — Database
- **React Hot Toast** — Notifications
- **Vercel** — Deployment
